##  Capstone Project Summary

**Loan Management API** — built with Java 21, Spring Boot 3, Gradle, PostgreSQL, Hibernate, Docker and JWT.

Features: customer registration, loan product setup, loan application, approval/rejection, disbursement, repayment scheduling, balance calculation, audit trail, and secured endpoints — with validation, logging, tests, OpenAPI docs, and Actuator health checks.
